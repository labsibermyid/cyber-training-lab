# Sample — incident-response

Upload file sample ke folder ini dengan nama **sample.zip**.

- Tombol **Sample** di halaman utama otomatis aktif dan langsung mengunduh file ini.
- Batas upload lewat web GitHub: 25 MB per file.
- Untuk file berbahaya (malware), bungkus dalam ZIP berpassword (umumnya `infected`)
  dan tulis passwordnya di `sampleNote` pada materi.js.
